Java File System Operations (java.io.File)

Basic programs for checking file properties, listing directories, and deleting files.

These programs demonstrate the `File` class, which is used for managing file system entities (paths, directories) rather than reading or writing data.

Understanding Files and Paths

What is a File?

A **File** is a named, persistent collection of data (a sequence of bytes) stored on a non-volatile storage device (like a hard drive). In Java's I/O system, it is the primary object representing data storage on the local file system, distinguished by its name and type (extension).

What is a Path?

A **Path** is a string representation that precisely specifies the location of a file or directory within the file system hierarchy. There are two main types:

  • **Absolute Path:** The full path starting from the root of the file system (e.g., `C:\Users\Student\report.txt` on Windows).
  • **Relative Path:** The path defined based on the current working directory where the Java program is executed (e.g., `data\file.csv`).

10 Key Concepts for java.io.File

  1. **Metadata Only:** A `File` object primarily manages the **path name** and **metadata**; it does not contain the file's actual data content.
  2. **Not for I/O:** You must use streams (FileInputStream, FileReader, etc.) to read or write data to the file represented by the object.
  3. **Existence Check:** Use the exists() method to verify if the file or directory exists on the file system.
  4. **Type Check:** Methods like isFile() and isDirectory() help determine the type of the path represented.
  5. **Platform Independence:** The class internally handles OS-specific path separators and conventions (e.g., it works on Windows, Linux, or macOS).
  6. **Creation:** Use createNewFile() to atomically create a new empty file, or mkdir()/ mkdirs() to create directories.
  7. **Deletion:** The delete() method permanently removes the file or directory (must be empty).
  8. **Immutability:** The path name associated with a `File` object cannot be changed after the object is created.
  9. **Path Retrieval:** Methods like getName(), getAbsolutePath(), and getParent() extract components of the path.
  10. **Last Modified:** The lastModified() method is crucial for tracking when the file was last changed.

1. FileInfo.java: Check Properties and Create File

This program shows how to check if a file or directory exists and displays important metadata like size, name, and modification time.

Source Code:

<code>
import java.io.File;
import java.io.IOException;
import java.text.SimpleDateFormat;
import java.util.Date;

public class FileInfo {
    public static void main(String[] args) {
        // 1. Create a File object pointing to the file path
        File myFile = new File("test_document.txt");
        
        // Use SimpleDateFormat for readable date display
        SimpleDateFormat sdf = new SimpleDateFormat("MM/dd/yyyy HH:mm:ss");

        if (myFile.exists()) {
            System.out.println("--- File Properties ---");
            // 2. Display basic metadata
            System.out.println("Name: " + myFile.getName());
            System.out.println("Path: " + myFile.getAbsolutePath());
            System.out.println("Is Directory? " + myFile.isDirectory());
            System.out.println("Is File? " + myFile.isFile());
            // 3. Get size in bytes
            System.out.println("Size (Bytes): " + myFile.length());
            // 4. Get last modified time
            System.out.println("Last Modified: " + sdf.format(new Date(myFile.lastModified())));
            
        } else {
            System.out.println("File does not exist. Attempting to create it...");
            try {
                // 5. Create the file if it doesn't exist
                if (myFile.createNewFile()) {
                    System.out.println("File created successfully: " + myFile.getName());
                } else {
                    System.out.println("File already exists or creation failed.");
                }
            } catch (IOException e) {
                System.out.println("An I/O error occurred during file creation: " + e.getMessage());
            }
        }
    }
}
</code>

2. DirectoryLister.java: List Directory Contents

This program demonstrates how to list all files and subdirectories within a specific directory.

Source Code:

<code>
import java.io.File;

public class DirectoryLister {
    public static void main(String[] args) {
        // NOTE: "." refers to the current working directory where the program is executed
        File currentDir = new File("."); 

        if (currentDir.isDirectory()) {
            System.out.println("Listing contents of the current directory:");
            // 1. Get an array of File objects for all contents
            File[] files = currentDir.listFiles();

            if (files != null) {
                // 2. Loop through all items found
                for (File file : files) {
                    // 3. Check if the item is a directory or a file
                    String type = file.isDirectory() ? "[DIR]" : "[FILE]";
                    System.out.println(type + " " + file.getName());
                }
            } else {
                System.out.println("No contents found or access denied.");
            }
        } else {
            System.out.println("Path specified is not a valid directory.");
        }
    }
}
</code>

3. FileDelete.java: Create and Delete a File

A simple program to demonstrate how to create a file and then delete it from the file system.

Source Code:

<code>
import java.io.File;
import java.io.IOException;

public class FileDelete {
    public static void main(String[] args) {
        String fileName = "temp_delete_me.dat";
        File fileToDelete = new File(fileName);

        try {
            // 1. Ensure the file exists before attempting to delete
            if (fileToDelete.createNewFile()) {
                System.out.println("File created for deletion: " + fileName);
            } else {
                System.out.println("File already exists: " + fileName);
            }

            // 2. Check existence before deleting
            if (fileToDelete.exists()) {
                System.out.println("Confirmation: File exists. Proceeding with deletion...");

                // 3. Delete the file
                if (fileToDelete.delete()) {
                    System.out.println("SUCCESS: File deleted successfully.");
                } else {
                    System.out.println("FAILURE: Could not delete the file. Check permissions.");
                }
            } else {
                System.out.println("File not found or was already deleted.");
            }

        } catch (IOException e) {
            System.out.println("An I/O error occurred: " + e.getMessage());
        }
    }
}
</code>
For Windows, using file paths like "C:\\mydata\\file.txt" will use the operating system's native file system.
