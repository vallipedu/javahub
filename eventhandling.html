Understanding Event Handling in JavaFX

JavaFX follows a structured approach to handle events, ensuring that user actions like clicks or key presses are captured and responded to efficiently. The main objects involved in event handling include the Event Source (e.g., a Button), the Event Object (contains details about the event), and the Event Handler (code that responds to the event). These objects coordinate seamlessly: the source generates the event, the event object carries information, and the handler processes it.

Implementing EventHandler Class

You can implement an EventHandler by creating a class that implements the EventHandler<EventType> interface. This class must override the handle() method, which contains the logic to execute when the event occurs. Once the handler is defined, it is registered with a UI control (the listener), so it listens for events generated by that control.

How Listeners Listen to Events

A listener is essentially an object that monitors a particular source for specific types of events. When the source triggers an event, the listener detects it and passes the event to the associated handler. This mechanism ensures that only relevant events are processed, keeping the application responsive and organized.

Button Events

For a Button, you can add an event handler for the ActionEvent. Example:
button.setOnAction(new ButtonHandler()); Here, ButtonHandler is a class implementing EventHandler<ActionEvent>. Clicking the button triggers the handle() method.

                      Button btn = new Button("Click Me");
                     btn.setOnAction(new ButtonClickHandler());

                  // Separate EventHandler class
    public class ButtonClickHandler implements EventHandler<ActionEvent> {
        @Override
        public void handle(ActionEvent event) {
            System.out.println("Button was clicked!");
        }
    }

Mouse Events

Mouse actions like clicks, movement, or dragging generate MouseEvent. You can attach handlers to controls or scenes:
node.setOnMouseClicked(new MouseHandler()); The MouseHandler class implements EventHandler<MouseEvent> and handles specific mouse actions. 

    Button btn = new Button("Hover or Click Me");
                   btn.setOnMouseClicked(new MouseClickHandler());
                   //separate handler class
                   public class MouseClickHandler implements EventHandler<MouseEvent> {
                   @Override
                   public void handle(MouseEvent event) {
                   System.out.println("Mouse clicked on button!");
           }
    }
setOnMouseClicked,setOnMouseEntered,setOnMouseExited,setOnMouseDragged ..etc.

Keyboard Events

Keyboard actions such as pressing or releasing keys trigger KeyEvent. Handlers are registered with the scene or specific nodes:
scene.setOnKeyPressed(new KeyHandler()); The KeyHandler class implements EventHandler<KeyEvent> to respond to the key press events.

setOnKeyPressed,setOnKeyReleased,setOnKeyTyped
