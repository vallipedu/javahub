21. Problem Statement for Full-Stack: Construction Project Monitoring Dashboard

You are required to build a **Construction Project Monitoring Dashboard**, similar to systems used by construction firms to track multiple ongoing projects. The dashboard must display project name, total budget, spent amount, and completion percentage. Students will design a clean interface showing **project progress**, **remaining budget**, and **status levels**.

Technological Requirements

  • Technologies to Use:
    • HTML — layout structure
    • CSS — dashboard styling
    • JavaScript — calculation logic
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries/frameworks
    • Client-side only (no backend)

Functional Requirements

  • 1. Project Data Handling:
    • Create an array of project objects:
      { projectName, totalBudget, spentAmount, completion }
    • Display all projects in an HTML table.
  • 2. Project Health Evaluation:
    • Calculate remaining budget:
      remaining = totalBudget - spentAmount
    • Determine project health:
    • • completion ≥ 80% → On Track
      • 50–80% → Needs Attention
      • < 50% → Behind Schedule
    • Display health status next to each project.

Testing Requirements

Validate your construction dashboard using the following 2 test cases:

  1. Test Case 1 — On Track:
    • Input: completion = 85%
    • Expected Output: On Track
  2. Test Case 2 — Behind Schedule:
    • Input: completion = 45%
    • Expected Output: Behind Schedule
