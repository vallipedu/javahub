Problem Statement: Simple ATM Withdrawal System

Develop a Java program that simulates a very basic ATM withdrawal operation. The system should store account details, accept withdrawal input, validate the balance, and update it accordingly. This experiment helps beginners practice simple OOP, conditions, and keyboard input using the Scanner class.

Functional Requirements

  • The system must store Account details:
    • Account Number
    • Account Holder Name
    • Balance
  • User must be able to:
    • Enter withdrawal amount
    • Validate whether sufficient balance exists
    • Deduct balance if valid
    • Display updated balance
  • System must validate:
    • Withdrawal amount must be > 0
    • Withdrawal amount ≤ balance
  • System must show appropriate messages:
    • “Insufficient Balance”
    • “Invalid Withdrawal Amount”

Technical Requirements

  • Use an Account class with private fields.
  • Use methods for:
    • Reading account details
    • Performing withdrawal
    • Displaying balance
  • Use the Scanner class for input.
  • Apply encapsulation to protect account data.
  • Use conditional statements for withdrawal validation.

Testing Requirements

Your program must demonstrate correctness using the following test cases:

  1. Test Case 1 — Successful Withdrawal
    • Balance: 5000
    • Withdrawal: 2000
    • Expected Output:
      • Withdrawal Successful
      • Updated Balance: 3000
  2. Test Case 2 — Insufficient Balance
    • Balance: 1000
    • Withdrawal: 3000
    • Expected Output: “Insufficient Balance”
