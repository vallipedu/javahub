Problem Statement: Simple Electricity Bill System

Develop a Java program that computes the electricity bill for a household customer. The system should read consumer details, number of units consumed, calculate the total bill based on simple slab rates, and display a formatted bill summary. This experiment is ideal for beginners to practice basic OOP, arithmetic operations, validation, and user input using the Scanner class.

Functional Requirements

  • The system must store customer details:
    • Consumer Number
    • Consumer Name
    • Units Consumed
  • The program must calculate the bill using slab rates:
    • 0–100 units → ₹3 per unit
    • 101–200 units → ₹4 per unit
    • Above 200 units → ₹5 per unit
  • The system must compute:
    • Total Bill Amount
  • The system must validate that units consumed is a non-negative value.
  • The bill summary must clearly display all details and computed amount.

Technical Requirements

  • Use a Customer class with private fields.
  • Use methods for:
    • Reading customer details
    • Computing the bill
    • Displaying bill details
  • Use the Scanner class for input.
  • Apply encapsulation to protect customer data.
  • Use simple conditional statements to implement slab rates.
  • Use simple validation for unit input.

Testing Requirements

Your program must demonstrate correctness using the following test cases:

  1. Test Case 1 — Moderate Consumption
    • Units: 150
    • Expected Calculation:
      100 × 3 = 300
      50 × 4 = 200
      Total = 500
  2. Test Case 2 — Invalid Units
    • Units Entered: -20
    • Expected Result: Program rejects negative units and asks for valid input.
