Problem Statement: Simple Shopping Billing System

Develop a Java program that generates a bill for items purchased in a shop. The system should allow entering multiple item names, quantities, and prices, calculate the total bill amount, and display a formatted bill summary. This experiment helps beginners practice basic OOP, arrays, arithmetic operations, and keyboard input using the Scanner class.

Functional Requirements

  • The system must store details for each item:
    • Item Name
    • Quantity
    • Price per Unit
  • The system must:
    • Read the number of items
    • Read details for each item
    • Compute item-wise total = quantity × price
    • Compute final bill amount
  • The system must validate that:
    • Quantity is positive
    • Price is non-negative
  • The program must display a clear formatted bill receipt.

Technical Requirements

  • Use an Item class with private fields.
  • Use an array of Item objects to store multiple purchased items.
  • Use methods for:
    • Reading item details
    • Calculating item total
    • Displaying item summary
  • Use the Scanner class for keyboard input.
  • Use simple encapsulation to protect item data.
  • Use simple loops and arithmetic to compute total bill.

Testing Requirements

Your program must demonstrate correctness using the following test cases:

  1. Test Case 1 — Multiple Items
    • Item 1: Pen, Qty = 2, Price = 10
    • Item 2: Notebook, Qty = 1, Price = 50
    • Expected Result:
      Item 1 Total = ₹20
      Item 2 Total = ₹50
      Final Bill = ₹70
  2. Test Case 2 — Invalid Quantity
    • Quantity entered: -3
    • Expected Result: Program must reject negative quantity and ask again
