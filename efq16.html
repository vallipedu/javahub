16. Problem Statement for Full-Stack: Hospitality Service Monitoring Dashboard

You are required to build a **Hospitality Service Monitoring Dashboard** that tracks customer service requests in a hotel. This system simulates how hotels manage room service, housekeeping, and maintenance tasks. Students will design a clean dashboard displaying **guest requests**, **service category**, and **request status**.

Technological Requirements

  • Technologies to Use:
    • HTML — dashboard layout
    • CSS — styling and formatting
    • JavaScript — status tracking logic
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries/frameworks
    • Client-side only (no backend)

Functional Requirements

  • 1. Guest Request Data Handling:
    • Create an array of service request objects:
      { guestName, roomNumber, requestType, priority }
    • Display all service requests in an HTML table.
  • 2. Priority-Based Status System:
    • Assign service status based on request priority:
    • • If priority = "High" → Immediate Attention
      • If priority = "Medium" → Attend Soon
      • If priority = "Low" → Normal Queue
    • Display the assigned status next to each request.

Testing Requirements

Validate your hospitality dashboard using the following 2 test cases:

  1. Test Case 1 — High Priority:
    • Input: priority = "High"
    • Expected Output: Immediate Attention
  2. Test Case 2 — Normal Queue:
    • Input: priority = "Low"
    • Expected Output: Normal Queue
