15. Problem Statement for Full-Stack: Sports Performance Analytics Dashboard

You are required to build a **Sports Analytics Dashboard** that tracks player performance metrics in a match. This system simulates how coaches and analysts evaluate players based on **score**, **speed**, and **stamina**. Students will design a neat dashboard displaying player statistics along with a simple **performance rating**.

Technological Requirements

  • Technologies to Use:
    • HTML — layout structure
    • CSS — styling the dashboard
    • JavaScript — performance analysis logic
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries/frameworks
    • Client-side only (no backend)

Functional Requirements

  • 1. Player Data Handling:
    • Create an array of player objects:
      { playerName, score, speed, stamina }
    • Display all players in an HTML table.
  • 2. Performance Rating System:
    • Calculate player performance using the rule:
    • performance = (score + speed + stamina) / 3
    • Classify the performance:
    • • ≥ 80 → Excellent
      • 60–80 → Good
      • 40–60 → Average
      • < 40 → Poor
    • Show the rating next to each player.

Testing Requirements

Validate your sports analytics system using the following 2 test cases:

  1. Test Case 1 — Excellent Player:
    • Input: score=90, speed=85, stamina=88
    • Expected Output: Performance ≥ 80 → Excellent
  2. Test Case 2 — Poor Player:
    • Input: score=20, speed=35, stamina=30
    • Expected Output: Performance < 40 → Poor
