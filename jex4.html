Problem Statement: Simple Student–Course Management System

Create a basic Java application that manages a student's details and their marks in 5 subjects. This program is designed to help beginners practice simple object-oriented programming concepts, arrays, and keyboard input using the Scanner class.

Functional Requirements

  • The system must store the student's ID and name.
  • The program must read marks for 5 subjects using an array.
  • The application must:
    • Read all inputs using Scanner
    • Calculate total marks
    • Calculate average marks
    • Display complete student information
  • The system must validate that marks are between 0 and 100.

Technical Requirements

  • Use a Student class to represent student data.
  • Use arrays to store marks for 5 subjects.
  • Use methods for reading input, computing total and average, and displaying results.
  • Use the Scanner class for user input.
  • Apply encapsulation using private fields and public methods.
  • Use simple validation for mark inputs.

Testing Requirements

Your program must verify correctness using the following test cases:

  1. Test Case 1 — High Scorer
    • Input Marks: 90, 85, 88, 92, 80
    • Expected Output: Total = 435, Average = 87.0
  2. Test Case 2 — Average Scorer
    • Input Marks: 50, 60, 55, 45, 40
    • Expected Output: Total = 250, Average = 50.0
