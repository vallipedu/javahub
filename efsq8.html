08. Problem Statement for Full-Stack: Student Learning Progress Tracker

You are required to develop a **simple Learning Progress Tracking System** for the Education domain. This problem helps students understand how online learning platforms track student course completion, performance, and learning status. Build a clean dashboard that displays **student progress data** and classifies their **learning status**.

Technological Requirements

  • Technologies to Use:
    • HTML — for structure
    • CSS — for dashboard styling
    • JavaScript — for progress calculation
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries or frameworks
    • Browser-only (no backend)

Functional Requirements

  • 1. Student Progress Data Handling:
    • Create an array of student objects:
      { studentName, completedModules, totalModules }
    • Calculate each student’s progress percentage:
    • progress = (completedModules / totalModules) * 100
    • Display all students in an HTML table with: Name, Completed Modules, Progress %.
  • 2. Learning Status Classification:
    • Based on progress percentage, classify status:
    • • ≥ 90% → Excellent
      • 70–90% → Good
      • 50–70% → Average
      • < 50% → Needs Improvement
    • Display the status next to each student.

Testing Requirements

Validate your system using the following 2 test cases:

  1. Test Case 1 — Excellent Performer:
    • Input: completedModules = 18, totalModules = 20
    • Expected Output: Progress ≥ 90% → Excellent
  2. Test Case 2 — Needs Improvement:
    • Input: completedModules = 6, totalModules = 15
    • Expected Output: Progress < 50% → Needs Improvement
