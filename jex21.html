Problem Statement: Highest & Lowest Marks Analyzer

Develop a Java program that reads student marks from a 2D array and identifies the highest and lowest marks in each subject, ignoring subjects marked as Absent. This experiment helps beginners understand 2D array traversal, conditional checks, and extracting meaningful insights from tabular data.

Functional Requirements

  • The system must store all student marks in a 2D integer array.
  • The program must:
    • Read all marks from the table
    • Ignore entries marked as Absent
    • Identify the highest and lowest marks in each subject
    • Display the student name and marks for each result
  • The output must clearly show:
    • Highest scorer per subject
    • Lowest scorer per subject

Technical Requirements

  • Use a 2D array to store marks.
  • Use a String array for storing student names.
  • Use loops to:
    • Traverse each subject column
    • Find highest & lowest values
  • Use conditions to skip "Absent" values.
  • Use variables to track:
    • Max value & name
    • Min value & name

Testing Requirements

Your program must demonstrate correctness using these test cases:

  1. Test Case 1 — Highest in Java
    • Expected: Aditya with 95
  2. Test Case 2 — Lowest in C
    • Expected: Vikram with 35
