1. How to handle events in JavaFX?

In JavaFX, events are handled through an event-driven model. Event sources (like buttons) generate events, and event handlers respond to them. You can register event handlers using the setOnAction() or addEventHandler() methods.

2. How to handle keyboard and mouse events? Explain with an example.

JavaFX provides dedicated event classes such as KeyEvent and MouseEvent. You can register listeners using methods like setOnKeyPressed() or setOnMouseClicked(). 

TextField tf = new TextField();
tf.setOnKeyPressed(e -> System.out.println("Key Pressed: " + e.getCode()));

Pane pane = new Pane();
pane.setOnMouseClicked(e -> System.out.println("Mouse Clicked at: " + e.getX() + ", " + e.getY()));

3. How to display text in JavaFX Scene?

The Text class is used to display text in a JavaFX scene. You can specify font, color, and position. 

Text message = new Text(50, 100, "Welcome to JavaFX!");
message.setFont(Font.font("Arial", 24));
message.setFill(Color.BLUE);

4. How to display an image?

The Image and ImageView classes are used to display images. 

Image img = new Image("file:photo.png");
ImageView imageView = new ImageView(img);
imageView.setFitWidth(200);
imageView.setPreserveRatio(true);

5. What are main components of JavaFX App Window Structure?

A JavaFX application window consists of three main components:

  • Stage: The top-level container (main window).
  • Scene: Holds the visual elements (nodes).
  • Nodes: Elements like buttons, labels, images, etc.

6. What are advantages of JavaFX Scene Builder over writing code using packages?

Scene Builder provides a visual interface for designing layouts, making development faster and less error-prone. It auto-generates FXML, allowing developers to focus more on logic than manual UI coding.

7. What is role of layout in JavaFX? List different layouts.

Layouts define how nodes are arranged in a scene. JavaFX offers several layout panes, such as:

  • FlowPane
  • BorderPane
  • GridPane
  • VBox and HBox
  • StackPane

8. Explain GridPane layout. When should we use this layout?

GridPane arranges nodes in a flexible grid of rows and columns. It is ideal when you need form-like structures (e.g., login forms, data entry screens).

9. How do you handle button press event?

Button press events are handled using setOnAction(). 

Button btn = new Button("Click Me");
btn.setOnAction(e -> System.out.println("Button Pressed!"));

10. How do you lay out nodes in Scene graph?

Nodes are added to layout panes, which are part of a hierarchical Scene Graph. Each parent node can contain multiple children nodes, forming a tree structure that JavaFX renders efficiently.
