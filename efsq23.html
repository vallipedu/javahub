23. Problem Statement for Full-Stack: Environmental Monitoring Dashboard

You are required to build an **Environmental Monitoring Dashboard**, similar to systems used in pollution control, climate tracking, and smart city environmental units. The dashboard must display air quality parameters, pollution index, and categorize environmental condition levels. Students will design a clean interface showing **location-wise environmental readings** and **health indicators**.

Technological Requirements

  • Technologies to Use:
    • HTML — interface structure
    • CSS — dashboard styling
    • JavaScript — pollution evaluation logic
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries/frameworks
    • Client-side only (no backend)

Functional Requirements

  • 1. Environmental Data Handling:
    • Create an array of environmental measurement objects:
      { location, pm25, pm10, temperature }
    • Display all monitoring data in an HTML table.
  • 2. Air Quality Index (AQI) Categorization:
    • Calculate AQI using:
    • aqi = pm25 + (pm10 * 0.5)
    • Categorize based on AQI value:
    • • aqi ≤ 50 → Good
      • 51–100 → Moderate
      • 101–200 → Unhealthy
      • > 200 → Hazardous
    • Display AQI and category for each location.

Testing Requirements

Validate your environmental monitoring dashboard using the following 2 test cases:

  1. Test Case 1 — Good Air Quality:
    • Input: pm25 = 20, pm10 = 40
    • Expected Output: aqi = 20 + 20 = 40 → Good
  2. Test Case 2 — Hazardous:
    • Input: pm25 = 180, pm10 = 100
    • Expected Output: aqi = 180 + 50 = 230 → Hazardous
