Interfaces in Java – Foundation to Implementation

Expert View

As a software engineer at NBKRIST, I often tell students that understanding interfaces is like understanding the nervous system of Java — it defines communication and consistency. At Vidyanagar, we use interfaces to connect components cleanly, ensuring flexibility and security. Interfaces are the foundation of modern frameworks and layered architectures.

Introduction

An interface in Java defines a contract for what a class must do without dictating how it does it. It supports abstraction and allows unrelated classes to share capabilities through implementation.

Declaration of Interface

interface College { String NAME = "NBKRIST"; void showDetails(); }
Note: Variables in interfaces are public, static and final by default.

Implementation of Interface

class Department implements College { public void showDetails(){ System.out.println("Department of CSE - " + NAME + ", Vidyanagar"); } } class Demo { public static void main(String[] args){ Department d = new Department(); d.showDetails(); } }
Output:
Department of CSE - NBKRIST, Vidyanagar

Multiple Interfaces

interface Sports { void play(); } interface Academics { void learn(); } class Student implements Sports, Academics { public void play(){ System.out.println("Playing Cricket at Vidyanagar"); } public void learn(){ System.out.println("Learning Interfaces in " + College.NAME); } }
Output:
Playing Cricket at Vidyanagar
Learning Interfaces in NBKRIST

Java supports multiple inheritance of type using interfaces, unlike classes, which cannot inherit from multiple classes.

Nested Interfaces

interface University { interface Department { void display(); } } class ECE implements University.Department { public void display(){ System.out.println("Nested Interface Example: ECE Department - NBKRIST, Vidyanagar"); } }
Output:
Nested Interface Example: ECE Department - NBKRIST, Vidyanagar

Inheritance of Interfaces

interface Campus { void campusName(); } interface Hostels extends Campus { void hostelDetails(); } class NBKHostel implements Hostels { public void campusName(){ System.out.println("Campus: NBKRIST, Vidyanagar"); } public void hostelDetails(){ System.out.println("Hostel: Silicon Block"); } }
Output:
Campus: NBKRIST, Vidyanagar
Hostel: Silicon Block

How Multiple Inheritance is Achieved in Java

interface Teacher { void guide(); } interface Researcher { void guide(); } class Professor implements Teacher, Researcher { public void guide(){ System.out.println("Guiding students at NBKRIST, Vidyanagar"); } }
Output:
Guiding students at NBKRIST, Vidyanagar

Multiple inheritance through interfaces is possible since interfaces declare methods without implementations, removing ambiguity. Classes cannot do this because they inherit implementation, which may conflict.

Practice Questions

1. Define interface and its purpose.
An interface defines abstract behavior contracts.
2. Can interfaces extend another interface?
Yes, for multi-level abstraction.
3. What is the purpose of nested interfaces?
To logically group related functionalities.
4. Why can’t Java have multiple inheritance with classes?
To avoid ambiguity in method definitions.
5. How does Java achieve multiple inheritance safely?
By using interfaces that require explicit implementation.

Key Summary

  • Interfaces define the structure of behavior without implementation.
  • Constants in interfaces like NBKRIST, Vidyanagar are public and final.
  • Java achieves multiple inheritance safely using interfaces.
  • Nested and inherited interfaces organize and extend behavior.
  • Mastery of interfaces builds the foundation for understanding frameworks like Spring and JavaFX.
