01-Problem Statement: Student Grade System

Your task is to develop a **Full-Stack Web Application** that accepts an array of students with their marks, processes them using JavaScript, computes their **average marks**, and assigns a **final grade**. The output must be displayed as a clean HTML table.

Technological Requirements

  • Frontend Technologies:
    • Use HTML for structure.
    • Use CSS for styling and layout.
    • Use JavaScript for logic and data handling.
  • JavaScript Concepts Allowed:
    • Arrow functions
    • Event handling
    • Objects & Arrays
  • Backend Requirement:
    • No backend server required — browser-only application.

Functional Requirements

  • 1. Student Data Handling:
    • Create an array of student objects with properties:
      { studentName, Mathematics, Java, Python, AI, ML, CloudComputing }
    • Use JavaScript objects & arrays to manage marks.
  • 2. Grade & Output Generation:
    • Compute each student's average marks from all 7 subjects.
    • Assign grade based on percentage:
      A++ (≥ 90%), A+ (80–90), A (70–80), B (60–70), C (45–60), Fail (< 45%).
    • Output must be a formatted HTML table showing Name, Average, Grade.

Testing Requirements

Your application must validate correctness using the following **2 simple test cases**:

  1. Test Case 1:
    • Marks: 95, 90, 92, 94, 96, 93, 95
    • Expected Average: ~93–95
    • Expected Grade: A++
  2. Test Case 2:
    • Marks: 60, 62, 58, 65, 64, 61, 60
    • Expected Average: ~61–62
    • Expected Grade: B
