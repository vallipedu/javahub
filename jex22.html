Problem Statement: Student Topper Finder

Develop a Java program that reads student marks from a 2D array and identifies the overall topper based on the highest average across all attended subjects. This experiment helps students practice 2D arrays, skipping absentees, percentage calculation, and selecting the best performer.

Functional Requirements

  • The system must store all marks in a 2D integer array.
  • The program must:
    • Read marks from the table
    • Ignore entries marked as Absent
    • Calculate the average for every student
    • Identify the highest average
    • Display the topper's name and average
  • The average is computed only from attended subjects.

Technical Requirements

  • Use:
    • A 2D array for marks
    • A String array for student names
  • Use loops to:
    • Iterate through each student's row
    • Count attended subjects
    • Compute sum & average
  • Use conditions to skip "Absent".
  • Use variables to track:
    • Maximum average
    • Name of topper

Testing Requirements

Your program must display correct output for the following test cases:

  1. Test Case 1 — Expected Topper
    • Student: Aditya
    • Marks considered: 92, 95, 93, 88
    • Expected Average ≈ 92
  2. Test Case 2 — Second Highest
    • Student: Meenakshi
    • Expected Average ≈ 88.8
