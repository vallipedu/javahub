Problem Statement: Simple Employee Payroll System

Develop a Java program that manages basic payroll details for an employee. The system should read employee data, compute gross and net salary, and display a formatted payroll report. This program is ideal for beginners to practice basic OOP, arrays (optional), and user input using the Scanner class.

Functional Requirements

  • The system must store employee details:
    • Employee ID
    • Employee Name
    • Basic Salary
  • The program must allow entering:
    • HRA (Housing Allowance)
    • DA (Dearness Allowance)
    • PF (Provident Fund)
  • The system must compute:
    • Gross Salary = Basic + HRA + DA
    • Net Salary = Gross Salary − PF
  • The system must validate that salary and allowance values are non-negative.
  • The program must display a clear formatted payroll summary.

Technical Requirements

  • Use an Employee class with private fields.
  • Use methods for:
    • Reading employee details
    • Calculating gross salary
    • Calculating net salary
    • Displaying payroll details
  • Use the Scanner class for input.
  • Apply encapsulation to protect salary information.
  • Use simple validation for salary and deduction inputs.
  • Arrays may be used for storing payroll components (optional).

Testing Requirements

Your program must demonstrate correctness using the following test cases:

  1. Test Case 1 — Standard Payroll Case
    • Basic Salary: 20,000
    • HRA: 2,000
    • DA: 1,500
    • PF: 1,000
    • Expected Result: Gross = 23,500, Net = 22,500
  2. Test Case 2 — Invalid Salary Input
    • Basic Salary Entered: -5000
    • Expected Result: Program must reject negative salary and ask for valid entry
