Problem Statement: Identify Below-Average Students

Build a Java program that reads the provided student marks into a 2D array, computes each student's average (considering only attended subjects), computes the class average, and then identifies students whose average is below the class average. This exercise reinforces 2D arrays, missing-data handling (absentees), aggregation, and conditional filtering.

Functional Requirements

  • Load the dataset into a 2D array (or equivalent structure).
  • The program must compute:
    • Each student's average (ignore "Absent" columns for that student)
    • The overall class average (average of all student averages)
    • A list of students whose average is strictly below the class average
  • Display, for each below-average student:
    • Student Name
    • Student Average (rounded to 1 decimal place)
    • Number of subjects attended
  • Absentees must not be counted in the numerator or denominator for a student's average.

Technical Requirements

  • Use a 2D array (e.g., int[][]) for numeric marks and a parallel structure (e.g., String[]) for names. You may use sentinel values (like -1) to represent "Absent" internally.
  • Use loops to:
    • Calculate each student's sum and count of attended subjects
    • Compute each student's average
    • Compute the class average from student averages
    • Filter students below the class average
  • Format averages to one decimal place for output (use Math.round(x*10.0)/10.0 or System.out.printf).
  • Organize your code into methods for clarity (e.g., calculateStudentAverages, computeClassAverage, listBelowAverageStudents).

Testing Requirements

Verify functionality with these test checks (expected values are approximate rounded to 1 decimal):

  1. Test Case 1 — Individual Averages (sample)
    • Revathi average ≈ 86.2
    • Diya average ≈ 78.3
    • Meera average ≈ 88.6
  2. Test Case 2 — Class Average & Below-Average List
    • Compute class average (average of all student averages) — expected ≈ 73.6
    • Students with averages below class average (example expected list):
      • Venkat — average ≈ 64.0
      • Vikram — average ≈ 40.0
      • Saravana — average ≈ 27.3

Note: Exact class average and list may vary slightly depending on rounding; ensure you compute using full precision then format for display.
