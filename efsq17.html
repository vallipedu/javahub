17. Problem Statement for Full-Stack: Travel Booking Dashboard

You are required to build a **Travel Booking Dashboard** that simulates a basic online travel booking system. This dashboard helps users view available trips, prices, seating capacity, and booking status. Students will design a clean interface displaying **travel packages**, **availability**, and **booking confirmation logic**.

Technological Requirements

  • Technologies to Use:
    • HTML — dashboard layout
    • CSS — visual styling
    • JavaScript — booking logic
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries/frameworks
    • Client-side only (no backend)

Functional Requirements

  • 1. Travel Package Data Handling:
    • Create an array of travel package objects:
      { destination, price, seatsAvailable }
    • Display all packages in an HTML table.
  • 2. Booking Confirmation System:
    • Implement booking rules:
    • • If seatsAvailable > 0 → Booking Confirmed
      • If seatsAvailable = 0 → Sold Out
    • Display booking status next to each package.

Testing Requirements

Validate your travel booking dashboard using these 2 test cases:

  1. Test Case 1 — Booking Confirmation:
    • Input: seatsAvailable = 5
    • Expected Output: Booking Confirmed
  2. Test Case 2 — Sold Out:
    • Input: seatsAvailable = 0
    • Expected Output: Sold Out
