25. Problem Statement for Full-Stack: Satellite Monitoring Dashboard

You are required to build a **Satellite Monitoring Dashboard**, similar to systems used by space agencies and satellite operation centers. The dashboard must display satellite parameters including **altitude**, **speed**, and **signal strength**, and classify satellite status. Students will design a clean interface showing **satellite health**, **orbit details**, and **signal reliability**.

Technological Requirements

  • Technologies to Use:
    • HTML — structure for dashboard
    • CSS — styling and layout
    • JavaScript — satellite status logic
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries/frameworks
    • Client-side only (browser-based)

Functional Requirements

  • 1. Satellite Telemetry Data Handling:
    • Create an array of satellite objects:
      { satelliteName, altitude, speed, signalStrength }
    • Display all satellite readings in an HTML table.
  • 2. Satellite Status Classification:
    • Calculate satellite condition using:
    • healthScore = (altitude * 0.1) + (speed * 0.2) + (signalStrength * 0.7)
    • Based on healthScore classify as:
    • • ≥ 80 → Optimal
      • 50–79 → Stable
      • < 50 → Critical
    • Display satellite condition next to each entry.

Testing Requirements

Validate your satellite monitoring dashboard using the following 2 test cases:

  1. Test Case 1 — Optimal Satellite:
    • Input: altitude=500, speed=7, signalStrength=95
    • Expected Output: healthScore ≈ 89 → Optimal
  2. Test Case 2 — Critical Satellite:
    • Input: altitude=200, speed=5, signalStrength=20
    • Expected Output: healthScore ≈ 24 → Critical
