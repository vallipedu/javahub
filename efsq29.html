29. Problem Statement for Full-Stack: Cinema Ticket Booking Dashboard

You are required to build a **Cinema Ticket Booking Dashboard**, similar to systems used in multiplexes and online movie ticket booking apps. The dashboard must display **movie list, showtimes, seat availability**, and allow seat booking simulation. Students will design a clean interface showing **movie details**, **available seats**, and **booking confirmation**.

Technological Requirements

  • Technologies to Use:
    • HTML — UI structure
    • CSS — styling & layout
    • JavaScript — seat booking logic
  • JavaScript Concepts Allowed:
    • Objects & Arrays
    • Arrow Functions
    • Event Handling
  • Restrictions:
    • No external frameworks
    • Frontend-only implementation

Functional Requirements

  • 1. Movie & Show Data Handling:
    • Create an array of movie objects:
      { movieName, showTime, totalSeats, bookedSeats }
    • Display all movies with showtimes and available seats.
  • 2. Seat Booking Simulation:
    • When the user selects a movie, reduce bookedSeats by 1.
    • Update seat availability using:
      availableSeats = totalSeats - bookedSeats
    • If availableSeats = 0 → show House Full.
    • Display a booking confirmation message.

Testing Requirements

Validate your cinema booking dashboard with the following 2 test cases:

  1. Test Case 1 — Successful Booking:
    • Input: totalSeats = 100, bookedSeats = 90
    • Expected Output: availableSeats = 10 → booking reduces it to 9
  2. Test Case 2 — House Full:
    • Input: totalSeats = 50, bookedSeats = 50
    • Expected Output: "House Full" message displayed
