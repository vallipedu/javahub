22. Problem Statement for Full-Stack: Social Media Engagement Analytics Dashboard

You are required to build a **Social Media Engagement Analytics Dashboard**, similar to systems used by platforms like Instagram, YouTube, or Twitter. The dashboard must display post details, number of likes, comments, and shares, and calculate engagement rate. Students will design a clean interface that visualizes **post performance** and **engagement score**.

Technological Requirements

  • Technologies to Use:
    • HTML — interface structure
    • CSS — styling and formatting
    • JavaScript — analytics logic
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries/frameworks
    • Client-side only (no backend)

Functional Requirements

  • 1. Social Media Post Data Handling:
    • Create an array of posts:
      { postTitle, likes, comments, shares }
    • Display all posts in an HTML table.
  • 2. Engagement Rate Calculation:
    • Calculate engagement score using:
    • engagement = likes + (comments * 2) + (shares * 3)
    • Rate the post:
    • • ≥ 300 → Viral
      • 150–300 → High Engagement
      • 50–150 → Moderate Engagement
      • < 50 → Low Engagement
    • Display engagement status next to each post.

Testing Requirements

Validate your analytics dashboard using the following 2 test cases:

  1. Test Case 1 — Viral Post:
    • Input: likes=100, comments=50, shares=30
    • Expected Output: engagement = 100 + 100 + 90 = 290 → High Engagement
  2. Test Case 2 — Low Engagement:
    • Input: likes=10, comments=5, shares=2
    • Expected Output: engagement = 10 + 10 + 6 = 26 → Low Engagement
