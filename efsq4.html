04. Problem Statement for Full-Stack: Patient Health Monitoring System

You are asked to develop a **simple and intuitive Healthcare Monitoring Dashboard**. This system simulates how hospitals track a patient's basic vital signs. Students will build a small, clean, browser-based dashboard that displays **live health readings** and identifies whether the patient is in a safe condition.

Technological Requirements

  • Technologies to Use:
    • HTML — for structure
    • CSS — for styling the dashboard
    • JavaScript — to update and analyze patient vitals
  • JavaScript Concepts Allowed:
    • Arrow functions
    • Event handling
    • Objects & Arrays
  • Restrictions:
    • No external libraries or frameworks
    • Browser-only implementation (no backend)

Functional Requirements

  • 1. Vital Data Simulation:
    • Create a JavaScript object to represent patient vitals:
      { heartRate, oxygenLevel, temperature }
    • Values can be manually entered or auto-generated using random numbers.
    • Display the vital readings in an HTML table.
  • 2. Health Status Evaluation:
    • Determine patient status based on vitals:
    • • If oxygenLevel < 90 → Critical
      • If temperature > 101 → Fever Alert
      • If heartRate not in 60–100 → Abnormal Heart Rate
      • Otherwise: Stable
    • Display the final health status clearly in a separate section.

Testing Requirements

Validate your system with these 2 basic test cases:

  1. Test Case 1 — Low Oxygen Alert:
    • Input: oxygenLevel = 85
    • Expected Output: Critical
  2. Test Case 2 — Fever Detection:
    • Input: temperature = 102
    • Expected Output: Fever Alert
