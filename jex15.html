Problem Statement: Simple Exam Grade Calculator

Develop a Java program that calculates a student’s exam grade based on marks entered for multiple subjects. The system must store student details, read marks using an array, compute total and average, and assign a grade. This experiment helps beginners practice arrays, OOP, and user input using the Scanner class.

Functional Requirements

  • The system must store Student details:
    • Student ID
    • Student Name
  • The program must:
    • Read the number of subjects
    • Use an integer array to store marks
    • Calculate total and average marks
    • Assign grade based on average
    • Display the complete report
  • The system must validate that:
    • Marks must be between 0 and 100
    • Number of subjects must be positive
  • Grade assignment:
    • 90–100 → A
    • 80–89 → B
    • 70–79 → C
    • 60–69 → D
    • Below 60 → Fail

Technical Requirements

  • Use a Student class with private fields.
  • Use an integer array to store marks.
  • Use methods for:
    • Reading student details
    • Reading marks
    • Calculating total and average
    • Determining grade
    • Displaying final report
  • Use the Scanner class for input.
  • Apply encapsulation to protect student data.
  • Use loops and conditions for validation and calculations.

Testing Requirements

Your program must demonstrate correctness using the following test cases:

  1. Test Case 1 — High Performer
    • Subjects: 3
    • Marks: 95, 90, 92
    • Expected Output:
      • Total = 277
      • Average = 92.3
      • Grade = A
  2. Test Case 2 — Fail Case
    • Subjects: 4
    • Marks: 50, 45, 55, 40
    • Expected Output:
      • Total = 190
      • Average = 47.5
      • Grade = Fail
