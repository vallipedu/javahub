14. Problem Statement for Full-Stack: Weather Monitoring Dashboard

You are required to build a **simple Weather Monitoring System**. This dashboard simulates how meteorological departments track basic weather indicators such as **temperature**, **humidity**, and **wind speed**. Students will develop a clear and user-friendly dashboard that displays weather readings and provides alerts for extreme conditions.

Technological Requirements

  • Technologies to Use:
    • HTML — for page structure
    • CSS — for styling the dashboard
    • JavaScript — for weather condition analysis
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries or frameworks
    • Client-side only (no backend)

Functional Requirements

  • 1. Weather Data Handling:
    • Create a JavaScript object for weather data:
      { temperature, humidity, windSpeed }
    • Display the weather readings in an HTML table.
  • 2. Weather Alert System:
    • Generate alerts based on the readings:
    • • If temperature > 40°C → Heat Wave Alert
      • If humidity < 30% → Low Humidity Alert
      • If windSpeed > 60 km/h → High Wind Alert
      • Otherwise → Normal Weather Conditions
    • Display the weather alert below the table.

Testing Requirements

Validate your weather system using the following 2 test cases:

  1. Test Case 1 — Heat Alert:
    • Input: temperature = 42
    • Expected Output: Heat Wave Alert
  2. Test Case 2 — High Wind:
    • Input: windSpeed = 75
    • Expected Output: High Wind Alert
