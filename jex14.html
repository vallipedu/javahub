Problem Statement: Simple Bus Pass System

Develop a Java program that generates a simple monthly bus pass for a student. The system should store student details, accept monthly pass cost, and calculate the total amount for multiple months. This experiment helps beginners practice arrays, basic OOP, and keyboard input using the Scanner class.

Functional Requirements

  • The system must store Student details:
    • Student ID
    • Student Name
    • Route Number
  • The system must:
    • Read the number of months the student needs the bus pass
    • Read monthly pass amount using a float array
    • Calculate total amount
    • Display final bus pass bill
  • Validation:
    • Number of months must be positive
    • Pass amount must be greater than zero
  • The system must clearly display:
    • Student info
    • Total months
    • Total bus pass amount

Technical Requirements

  • Use a Student class with private fields.
  • Use a float array to store monthly pass amounts.
  • Use methods for:
    • Reading student details
    • Reading monthly pass amounts
    • Calculating total bill
    • Displaying summary
  • Use the Scanner class for input.
  • Use encapsulation with getters/setters.
  • Use loops and conditions for validation and summation.

Testing Requirements

Your program must demonstrate correctness using the following test cases:

  1. Test Case 1 — Normal Calculation
    • Months: 3
    • Amounts: 500, 500, 600
    • Expected Output: Total = 1600
  2. Test Case 2 — Invalid Pass Amount
    • Input: -200
    • Expected Output: Reject and ask again
