10. Problem Statement for Full-Stack: Smart Home IoT Monitoring System

You are required to build a **Smart Home IoT Monitoring Dashboard**. This system simulates how smart homes track device readings such as **room temperature**, **light intensity**, and **door status**. Students will create a simple and intuitive dashboard that displays device data and alerts the homeowner when unusual conditions occur.

Technological Requirements

  • Technologies to Use:
    • HTML — smart home dashboard layout
    • CSS — UI styling
    • JavaScript — IoT data analysis
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries
    • Client-side only (no backend)

Functional Requirements

  • 1. Smart Device Data Handling:
    • Create an array of IoT device objects:
      { deviceName, temperature, lightLevel, doorStatus }
    • Display all device readings in an HTML table.
  • 2. IoT Alert System:
    • Generate alerts based on the device readings:
    • • If temperature > 35°C → High Temperature Alert
      • If lightLevel < 20 → Low Light Warning
      • If doorStatus = "Open" → Door Left Open Alert
      • Otherwise → All Conditions Normal
    • Display alerts clearly next to each device entry.

Testing Requirements

Validate your smart home system using the following 2 test cases:

  1. Test Case 1 — Temperature Alert:
    • Input: temperature = 38
    • Expected Output: High Temperature Alert
  2. Test Case 2 — Door Open Alert:
    • Input: doorStatus = "Open"
    • Expected Output: Door Left Open Alert
