19. Problem Statement for Full-Stack: Insurance Claim Processing Dashboard

You are required to build a **simple Insurance Claim Processing Dashboard**, similar to systems used by health and vehicle insurance companies. The dashboard must display claim details, claim amount, claim type, and claim approval status. Students will design a clean user interface to visualize **claim history**, **claim type**, and **status evaluation**.

Technological Requirements

  • Technologies to Use:
    • HTML — layout and content
    • CSS — styling and formatting
    • JavaScript — approval logic
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries/frameworks
    • Client-side only (no backend)

Functional Requirements

  • 1. Insurance Claim Data Handling:
    • Create an array of claim objects:
      { claimantName, claimType, claimAmount, documentStatus }
    • Display all claims in an HTML table.
  • 2. Claim Approval System:
    • Implement approval rules:
    • • If documentStatus = "Verified" AND claimAmount ≤ 50000 → Approved
      • If documentStatus = "Verified" AND claimAmount > 50000 → Review Required
      • If documentStatus = "Pending" → Documents Needed
    • Display approval status next to each claim.

Testing Requirements

Validate your insurance claim dashboard using the following 2 test cases:

  1. Test Case 1 — Claim Approved:
    • Input: documentStatus = "Verified", claimAmount = 30000
    • Expected Output: Approved
  2. Test Case 2 — Documents Needed:
    • Input: documentStatus = "Pending", claimAmount = 45000
    • Expected Output: Documents Needed
