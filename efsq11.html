11. Problem Statement for Full-Stack: OTT Content Recommendation Monitor

You are required to build a **simple OTT (Over-The-Top) Content Recommendation Dashboard**. This system simulates how platforms like Netflix, Hotstar, Amazon Prime, etc., track user watch history and generate basic recommendations. Students will design a clean dashboard that displays **watch history**, **genres**, and **recommended content**.

Technological Requirements

  • Technologies to Use:
    • HTML — to structure the dashboard
    • CSS — to style UI components
    • JavaScript — to generate recommendations
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external frameworks
    • Client-side only (no backend)

Functional Requirements

  • 1. Watch History Handling:
    • Create an array of watched items:
      { title, genre, duration }
    • Display all watched items in an HTML table.
  • 2. Recommendation Generation:
    • Identify the user's most-watched genre.
    • Generate at least **3 recommended items** of the same genre.
    • Display recommendations in a separate highlighted section.

Testing Requirements

Validate your OTT system using the following 2 test cases:

  1. Test Case 1 — Most Watched Genre:
    • Input: 5 watched movies, 3 of them are "Action".
    • Expected Output: "Action" must be selected as the preferred genre.
  2. Test Case 2 — Recommendation Count:
    • Input: Preferred genre = "Comedy"
    • Expected Output: At least 3 Comedy recommendations displayed.
