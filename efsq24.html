24. Problem Statement for Full-Stack: Ocean Monitoring Dashboard

You are required to build an **Ocean Monitoring Dashboard**, similar to systems used in marine research, tsunami monitoring, and environmental ocean studies. The dashboard must display various ocean parameters, including **temperature**, **salinity**, and **wave height**, and classify ocean conditions. Students will design a clean interface showing **region-wise ocean data** and **safety indicators**.

Technological Requirements

  • Technologies to Use:
    • HTML — structure for dashboard
    • CSS — styling and layout
    • JavaScript — ocean condition logic
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries/frameworks
    • Frontend only (browser-based)

Functional Requirements

  • 1. Ocean Sensor Data Handling:
    • Create an array of ocean observation objects:
      { region, temperature, salinity, waveHeight }
    • Display all ocean readings in an HTML table.
  • 2. Ocean Condition Classification:
    • Calculate ocean condition using rule:
    • riskScore = (temperature * 0.2) + (salinity * 0.3) + (waveHeight * 0.5)
    • Classify the ocean condition based on riskScore:
    • • ≤ 30 → Safe
      • 31–60 → Caution
      • > 60 → High Risk
    • Display risk classification next to each region.

Testing Requirements

Validate your ocean monitoring dashboard using the following 2 test cases:

  1. Test Case 1 — Safe Condition:
    • Input: temperature=20, salinity=30, waveHeight=10
    • Expected Output: riskScore = (4 + 9 + 5) = 18 → Safe
  2. Test Case 2 — High Risk:
    • Input: temperature=28, salinity=40, waveHeight=25
    • Expected Output: riskScore = (5.6 + 12 + 12.5) = 30.1 → Caution
      (If waveHeight increases beyond 30, risk turns High Risk)
