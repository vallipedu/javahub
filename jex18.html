Problem Statement: Simple Student Feedback Analyzer

Develop a Java program that collects feedback ratings from students for a course. The system should store 5 feedback scores in an array, calculate the average rating, and display the final feedback summary. This task helps beginners practice arrays, simple OOP, and keyboard input using the Scanner class.

Functional Requirements

  • The system must store course feedback details:
    • Course Name
    • Faculty Name
  • The system must:
    • Read 5 feedback ratings (values from 1 to 5)
    • Store them in an int array
    • Calculate the average rating
    • Display the summary in a clear format
  • Validation:
    • Each rating must be between 1 and 5 only

Technical Requirements

  • Use a Feedback class with private fields.
  • Use an int array to store ratings.
  • Use methods for:
    • Reading course & faculty details
    • Reading 5 ratings
    • Calculating average
    • Displaying final summary
  • Use Scanner for all user input.
  • Apply encapsulation for field protection.
  • Use loops & simple validation.

Testing Requirements

Your program must demonstrate correctness using the following test cases:

  1. Test Case 1 — Valid Ratings
    • Ratings: 5, 4, 4, 5, 5
    • Expected Average: 4.6
  2. Test Case 2 — Invalid Rating
    • Input: 7
    • Expected Result: System rejects and asks again
