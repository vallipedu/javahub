Java Exception Handling Programs

Collection of practical programs discussed in class for understanding Java Exception Handling (NBKRIST – CSE Dept).

Expert View

While teaching Exception Handling, I’ve noticed students grasp the concept best through code experimentation. Each of these examples demonstrates not just error catching but structured thinking. Real-world projects depend on reliable exception flow — ensuring the system never fails silently but informs and recovers gracefully.

ExceptionDemo.java 
import java.util.*;
public class ExceptionDemo {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    System.out.println("Enter two numbers:");
    try {
      int a = sc.nextInt(), b = sc.nextInt();
      System.out.println("Result: " + (a / b));
    } catch (ArithmeticException e) {
      System.out.println("Division by zero not allowed");
    } finally {
      sc.close();
      System.out.println("Scanner closed.");
    }
  }
}
    
Output:
Division by zero not allowed
Scanner closed.
MultipleCatch.java 
public class MultipleCatch {
  public static void main(String[] args) {
    try {
      int[] arr = {1, 2, 3};
      System.out.println(arr[5]);
      int x = 10 / 0;
    } catch (ArrayIndexOutOfBoundsException e) {
      System.out.println("Array index invalid");
    } catch (ArithmeticException e) {
      System.out.println("Division by zero");
    } catch (Exception e) {
      System.out.println("Unexpected error");
    }
  }
}
    
Output:
Array index invalid
MultipleTryCatchBlocks.java 
public class MultipleTryCatchBlocks {
  public static void main(String[] args) {
    try {
      int[] numbers = {1, 2, 3};
      System.out.println(numbers[5]);
    } catch (ArrayIndexOutOfBoundsException e) {
      System.out.println("Index out of bounds");
    }

    try {
      int result = 10 / 0;
    } catch (ArithmeticException e) {
      System.out.println("Divide by zero error");
    }
  }
}
    
Output:
Index out of bounds
Divide by zero error
ThrowsDemo.java 
public class ThrowsDemo {
  static void methodA() throws Exception {
    methodB();
  }
  static void methodB() throws Exception {
    throw new Exception("Thrown from methodB");
  }
  public static void main(String[] args) {
    try {
      methodA();
    } catch (Exception e) {
      System.out.println("Caught in main: " + e.getMessage());
    }
  }
}
    
Output:
Caught in main: Thrown from methodB
BlanketCatchDemo.java 
public class BlanketCatchDemo {
  public static void main(String[] args) {
    try {
      int[] arr = {1, 2, 3};
      System.out.println(arr[5]);
      int result = 10 / 0;
    } catch (Exception e) {
      System.out.println("Exception occurred: " + e.getMessage());
    }
  }
}
    
Output:
Exception occurred: Index 5 out of bounds for length 3
UserDefinedBusinessExceptionDemo.java 
class InSufficientFundsException extends Exception {
  InSufficientFundsException(String msg) { super(msg); }
}
public class UserDefinedBusinessExceptionDemo {
  static void withdraw(double bal, double amt) throws InSufficientFundsException {
    if (amt > bal) throw new InSufficientFundsException("Insufficient Funds");
    System.out.println("Withdrawal Successful!");
  }
  public static void main(String[] args) {
    try {
      withdraw(2000, 5000);
    } catch (InSufficientFundsException e) {
      System.out.println("Error: " + e.getMessage());
    }
  }
}
    
Output:
Error: Insufficient Funds

🔑 Key Summary

  • Each example demonstrates core exception mechanisms: try, catch, finally, throw, and throws.
  • Multiple catches allow precise error handling for various exception types.
  • Blanket catches should be used cautiously — specific exceptions provide clarity.
  • User-defined exceptions make code more expressive for business logic.
  • Every exception handling example ensures program stability and continuity.

By mastering these patterns, students can handle real-world failures gracefully and design resilient Java applications.
