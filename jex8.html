Problem Statement: Simple Cinema Ticket Booking System

Develop a Java program that books a cinema ticket for a customer. The system should read customer details, movie details, number of tickets required, calculate total amount, and display a formatted ticket receipt. This experiment is designed for beginners to practice basic OOP, input handling, and validation using the Scanner class.

Functional Requirements

  • The system must store Customer details:
    • Customer Name
    • Mobile Number
  • The system must store Movie details:
    • Movie Name
    • Show Time
    • Ticket Price
  • The user must be able to:
    • Enter number of tickets required
    • Calculate total cost
    • Display ticket booking receipt
  • The system must validate:
    • Ticket count must be positive
    • Ticket price must be non-negative
  • The final receipt must clearly show customer, movie, and payment details.

Technical Requirements

  • Use two simple classes:
    • Customer
    • Movie
  • Use private fields with encapsulation.
  • Use methods for:
    • Reading customer details
    • Reading movie details
    • Computing total amount
    • Displaying booking receipt
  • Use Scanner class for input.
  • Use basic validation for ticket count & price.
  • Optional: Store multiple movies using an array.

Testing Requirements

Your program must demonstrate correctness using the following test cases:

  1. Test Case 1 — Valid Booking
    • Movie: "Leo", Show Time: "7:00 PM", Price = ₹150
    • Tickets = 3
    • Expected Result: Total = ₹450 and receipt printed
  2. Test Case 2 — Invalid Ticket Count
    • Tickets Entered: -4
    • Expected Result: Program rejects negative count and asks again
