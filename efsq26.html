26. Problem Statement for Full-Stack: Power Grid Monitoring Dashboard

You are required to build a **Power Grid Monitoring Dashboard**, similar to systems used in electricity distribution and energy management centers. The dashboard must display **voltage**, **current**, and **load capacity** readings for different grid stations and classify grid stability. Students will design a clean interface showing **station-wise monitoring data** and **stability indicators**.

Technological Requirements

  • Technologies to Use:
    • HTML — dashboard structure
    • CSS — styling and layout
    • JavaScript — grid stability logic
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries/frameworks
    • Frontend only

Functional Requirements

  • 1. Grid Station Data Handling:
    • Create an array of grid station objects:
      { stationName, voltage, current, loadCapacity }
    • Display all station data in an HTML table.
  • 2. Grid Stability Classification:
    • Calculate stability index using formula:
    • stabilityIndex = (voltage * 0.4) + (current * 0.3) + (loadCapacity * 0.3)
    • Classify stations:
    • • ≥ 80 → Stable
      • 50–79 → Warning
      • < 50 → Critical
    • Display classification next to each station.

Testing Requirements

Validate your power grid dashboard using the following 2 test cases:

  1. Test Case 1 — Stable Grid:
    • Input: voltage=220, current=50, loadCapacity=70
    • Expected Output: stabilityIndex ≈ 110 → Stable
  2. Test Case 2 — Critical Grid:
    • Input: voltage=100, current=30, loadCapacity=20
    • Expected Output: stabilityIndex ≈ 47 → Critical
