02.Problem Statement for Full-Stack: Student Grade & Topper System

Develop a **Full-Stack Web Application (HTML + CSS + JavaScript)** that processes student marks, calculates their **average**, and identifies the **topper** among all students. The final output must be displayed cleanly in HTML tables.

Technological Requirements

  • Technologies to Use:
    • HTML — structure
    • CSS — styling
    • JavaScript — calculations & DOM updates
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Event Handling
    • Objects & Arrays
  • Restrictions:
    • No external libraries or frameworks
    • Browser-only implementation (No backend)

Functional Requirements

  • 1. Student Data & Average Calculation:
    • Create an array of student objects:
      { studentName, Mathematics, Java, Python, AI, ML, CloudComputing }
    • Compute each student’s average marks from all 7 subjects.
    • Display all students in an HTML table with: Name, Average.
  • 2. Topper Identification & Display:
    • Identify the student with the highest average marks among all students.
    • Display the topper’s full details: Name, all subject marks, average, and grade.
    • Topper output must appear separately and clearly highlighted.

Testing Requirements

You must validate correctness with these 3 test cases including topper verification:

  1. Test Case 1 — Topper Verification Logic:
    • Input: At least 3 students with different marks.
    • Expected Output:
      The highest-average student must appear under a separate **Topper Section** with full details.
