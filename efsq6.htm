06. Problem Statement for Full-Stack: Smart Irrigation Monitoring System

You are required to develop a **simple Agriculture Monitoring Dashboard**. This system simulates how modern farms use sensors to monitor field conditions and decide when to irrigate crops. Students will build a clean, easy-to-understand dashboard showing **soil moisture**, **temperature**, and **water level** status.

Technological Requirements

  • Technologies to Use:
    • HTML — to design the layout
    • CSS — to style the dashboard
    • JavaScript — to simulate and analyze field data
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external frameworks
    • Browser-only implementation (no backend)

Functional Requirements

  • 1. Field Data Simulation:
    • Create a JavaScript object with field vitals:
      { soilMoisture, temperature, waterLevel }
    • Values can be manually entered or auto-generated randomly.
    • Display the field readings in an HTML table.
  • 2. Irrigation Decision System:
    • Provide irrigation recommendations based on readings:
    • • If soilMoisture < 30 → Start Irrigation
      • If waterLevel < 20 → Low Water Tank Warning
      • If temperature > 40 → High Temperature Alert
      • Otherwise → Field Conditions Normal
    • Display the final irrigation status clearly in a dedicated section.

Testing Requirements

Validate your system using the following 2 test cases:

  1. Test Case 1 — Low Soil Moisture:
    • Input: soilMoisture = 25
    • Expected Output: Start Irrigation
  2. Test Case 2 — Low Water Level:
    • Input: waterLevel = 15
    • Expected Output: Low Water Tank Warning
