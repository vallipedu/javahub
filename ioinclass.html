1. FileCopy.java (Byte Stream)

This program uses raw **byte streams** (FileInputStream and FileOutputStream) to copy data byte-by-byte, suitable for all file types (binary or text).

<!-- Javadoc Comment --> 
/**
 * The FileCopy class demonstrates a basic file-to-file content transfer
 * using byte streams (FileInputStream and FileOutputStream).
 *
 * It reads data byte-by-byte from a source file and writes it to a destination file.
 * Proper exception handling and resource closure are implemented.
 *
 * @author HARI BABU MUTCHAKALA
 * @version 1.0
 * @since 2025-10-07
 */

Source Code:

<code>
import java.io.FileInputStream;
import java.io.FileNotFoundException;
import java.io.FileOutputStream;
import java.io.IOException;

public class FileCopy {
    public static void main(String[] args) {
        // Declare streams outside try-block for access in finally
        FileInputStream fis = null;
        FileOutputStream fos = null;
        int ch;

        try {
            // 1. Open streams for byte-level reading and writing
            fis = new FileInputStream("MyView.txt.txt");
            fos = new FileOutputStream("ASectionCSE.txt");

            do {
                // 2. Read one raw byte (8-bit) as an integer
                ch = fis.read();
                if (ch != -1) {
                    // 3. Write one raw byte to the output file
                    fos.write(ch);
                }
            } while (ch != -1); // Loop until End Of File (-1) is reached

        } catch (FileNotFoundException e) {
            System.out.println("File not found" + e.getMessage());
        } catch (IOException e) {
            System.out.println("IO Exception" + e.getMessage());
        } finally {
            // 4. Critical: Ensure resources are closed in the finally block
            try {
                if (fis != null) {
                    fis.close();
                }
                if (fos != null) {
                    fos.close();
                }
            } catch (IOException e) {
                System.out.println("IO Exception during close: " + e.getMessage());
            }
        }
    }
}
</code>

2. ReaderWriter.java (Character Stream)

This program uses **character streams** (FileReader and FileWriter) which are designed to handle text and encoding conversions, reading/writing one character (16-bit) at a time.

<!-- Javadoc Comment --> 
/**
 * ReaderWriter.java
 *
 * This class demonstrates basic character-stream file handling in Java
 * using FileReader and FileWriter. It reads content from a file named
 * "a.txt" character by character and writes that same content to a file
 * named "b.txt" until the end of the input file is reached (-1).
 *
 * The program includes basic exception handling for file-related issues
 * such as FileNotFoundException and general IOException.
 *
 * @author HARI BABU MUTCHAKALA
 * @version 1.0
 * @since 2025-10-08
 */

Source Code:

<code>
import java.io.FileReader;
import java.io.FileNotFoundException;
import java.io.IOException;
import java.io.FileWriter;

public class ReaderWriter {
    public static void main (String adasd[]){
        // FileReader and FileWriter are base character streams
        try {
            FileReader freader= new FileReader("a.txt");
            FileWriter fwriter = new FileWriter("b.txt");
            int data;
            
            do {
                // 1. Read one character (16-bit Unicode)
                data = freader.read();
                // 2. Write one character
                fwriter.write(data);
            } while(data != -1); // Loop until End Of File (-1)

            // 3. Close resources explicitly
            freader.close();
            fwriter.close();

        } catch(FileNotFoundException fe){
            System.out.println("Catching exception: Input file 'a.txt' not found.");
        } catch(IOException fe){
            System.out.println("Catching exception: An I/O error occurred during file operations.");
        }
    }
}
</code>

3. Buffering.java (Buffered Stream)

This is the most efficient method for text, using **buffered streams** (BufferedReader and PrintWriter) to read and write large blocks of data at once.

<!-- Javadoc Comment --> 
/**
 * Buffering.java
 *
 * This class demonstrates efficient character-stream file handling using
 * BufferedReader and PrintWriter. It reads content line by line from
 * "a.txt" and writes the content line by line to "kk.txt", leveraging
 * buffering for better performance than direct character-by-character I/O.
 *
 * @author HARI BABU MUTCHAKALA
 * @version 1.0
 * @since 2025-10-08
 */

Source Code:

<code>
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.FileNotFoundException;
import java.io.IOException;
import java.io.FileWriter;
import java.io.PrintWriter;

public class Buffering {
    public static void main (String adasd[]){
        try {
            // 1. Base stream for reading
            FileReader fr = new FileReader("a.txt");
            // 2. Wrapper stream for buffering (adds readLine() capability)
            BufferedReader reader = new BufferedReader(fr); 
            // 3. Base stream for writing
            FileWriter fw = new FileWriter("kk.txt");
            // 4. Wrapper stream for convenient writing (e.g., auto-flush, println)
            PrintWriter out = new PrintWriter(fw, true); 
            
            String data;

            // 5. Read lines using the efficient buffer (readLine() is very efficient)
            while((data = reader.readLine()) != null){
                // 6. Write line followed by a platform-specific newline
                out.println(data); 
            }

            // 7. Close the wrapper streams (which implicitly closes the underlying streams)
            reader.close();
            out.close();

        } catch(FileNotFoundException fe){
            System.out.println("Catching exception: Input file 'a.txt' not found.");
        } catch(IOException fe){
            System.out.println("Catching exception: An I/O error occurred during file operations.");
        }
    }
}
</code>
Best practice for Java I/O often involves using Buffered Streams (BufferedReader) combined with the try-with-resources statement (Java 7+) to ensure automatic resource cleanup.
