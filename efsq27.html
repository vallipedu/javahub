27. Problem Statement for Full-Stack: Wildlife Tracking Dashboard

You are required to build a **Wildlife Tracking Dashboard**, similar to systems used in national parks, wildlife sanctuaries, and conservation research labs. The dashboard must display movement patterns and health indicators of tracked wild animals. Students will design a clean interface showing **animal location data**, **activity status**, and **risk classification**.

Technological Requirements

  • Technologies to Use:
    • HTML — structure of dashboard
    • CSS — styling & formatting
    • JavaScript — tracking & risk logic
  • JavaScript Concepts Allowed:
    • Objects & Arrays
    • Arrow Functions
    • Event Handling
  • Restrictions:
    • No external libraries/frameworks
    • Frontend only (browser-based)

Functional Requirements

  • 1. Animal Tracking Data Handling:
    • Create an array of animal tracking objects:
      { animalName, location, movementSpeed, heartRate }
    • Display all animal details in an HTML table.
  • 2. Wildlife Risk Level Classification:
    • Calculate risk score:
    • riskScore = (movementSpeed * 0.4) + (heartRate * 0.6)
    • Classify risk level:
    • • ≤ 40 → Healthy
      • 41–70 → Observation Needed
      • > 70 → Critical
    • Display risk category next to each animal.

Testing Requirements

Validate your wildlife tracking dashboard with the following 2 test cases:

  1. Test Case 1 — Healthy Animal:
    • Input: movementSpeed = 10, heartRate = 30
    • Expected Output: riskScore = (4 + 18) = 22 → Healthy
  2. Test Case 2 — Critical Animal:
    • Input: movementSpeed = 25, heartRate = 80
    • Expected Output: riskScore = (10 + 48) = 58 → Observation Needed
      (If heartRate > 110 → Critical)
