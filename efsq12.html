12. Problem Statement for Full-Stack: Finance Analytics Dashboard

You are required to build a **Finance Analytics Dashboard** that helps analyze basic financial transactions. This system simulates how financial analysts monitor income and expenses and calculate the overall financial health of an individual or business. Students will design a clean dashboard showing **transaction records**, **category-wise totals**, and **overall balance**.

Technological Requirements

  • Technologies to Use:
    • HTML — to structure the dashboard
    • CSS — for styling components
    • JavaScript — for financial calculations
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external frameworks
    • Client-side only (no backend)

Functional Requirements

  • 1. Transaction Data Handling:
    • Create an array of transactions:
      { description, amount, type }
    • Type can be: "Income" or "Expense".
    • Display all transactions in an HTML table.
  • 2. Financial Summary Calculation:
    • Calculate:
    • • Total Income
      • Total Expenses
      • Net Balance (Income − Expenses)
    • Display the summary clearly at the bottom.

Testing Requirements

Validate your finance dashboard using the following 2 test cases:

  1. Test Case 1 — Income Calculation:
    • Input: Two Income transactions → 5000, 3000
    • Expected Output: Total Income = 8000
  2. Test Case 2 — Net Balance Calculation:
    • Input: Income = 10000, Expense = 4000
    • Expected Output: Net Balance = 6000
