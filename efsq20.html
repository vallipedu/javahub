20. Problem Statement for Full-Stack: Transportation Route Monitoring Dashboard

You are required to build a **Transportation Route Monitoring Dashboard**, simulating systems used by bus, taxi, and logistics companies. The dashboard must display vehicle routes, total distance, travel time, and route efficiency. Students will create a simple interface showing **route details**, **distance**, **speed**, and **efficiency rating**.

Technological Requirements

  • Technologies to Use:
    • HTML — layout structure
    • CSS — dashboard styling
    • JavaScript — efficiency calculation
  • JavaScript Concepts Allowed:
    • Arrow Functions
    • Objects & Arrays
    • Event Handling
  • Restrictions:
    • No external libraries/frameworks
    • Client-side only (no backend)

Functional Requirements

  • 1. Route Data Handling:
    • Create an array of route objects:
      { routeName, distance, travelTime }
    • Display all routes in an HTML table.
  • 2. Route Efficiency Rating:
    • Calculate average speed using the rule:
    • avgSpeed = distance / travelTime (in km/hr)
    • Determine efficiency:
    • • avgSpeed ≥ 60 → Highly Efficient
      • 40–60 → Moderately Efficient
      • < 40 → Poor Efficiency
    • Display efficiency next to each route.

Testing Requirements

Validate your transportation dashboard using the following 2 test cases:

  1. Test Case 1 — High Efficiency:
    • Input: distance=180 km, travelTime=3 hrs
    • Expected Output: avgSpeed = 60 → Highly Efficient
  2. Test Case 2 — Poor Efficiency:
    • Input: distance=100 km, travelTime=3 hrs
    • Expected Output: avgSpeed = 33 → Poor Efficiency
