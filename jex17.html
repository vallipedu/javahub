Problem Statement: Simple Hostel Mess Billing System

Develop a Java program that generates a monthly mess bill for a hostel student. The system should store student details, read per-day mess charges using an array, calculate the total mess bill, and display a formatted summary. This experiment helps beginners practice arrays, OOP, and keyboard input using the Scanner class.

Functional Requirements

  • The system must store Student details:
    • Student ID
    • Student Name
    • Room Number
  • The system must:
    • Read the number of days the student has taken mess
    • Store per-day mess charges in a float array
    • Calculate the total mess bill
    • Display all details in a formatted report
  • Validation:
    • Days must be between 1 and 31
    • Daily charge must be ≥ 0

Technical Requirements

  • Use a Student class with private fields and methods.
  • Use a float array to store daily mess charges.
  • Use methods for:
    • Reading student details
    • Reading daily mess charges
    • Calculating total bill
    • Displaying the final mess bill
  • Use the Scanner class for reading input.
  • Use encapsulation with getters/setters.
  • Use loops and conditions for validation.

Testing Requirements

Your program must demonstrate correctness using the following test cases:

  1. Test Case 1 — Valid Mess Bill
    • Days: 3
    • Charges: 80, 85, 75
    • Expected Output: Total = 240
  2. Test Case 2 — Invalid Charge Handling
    • Input: -50
    • Expected Result: System should reject negative charges
